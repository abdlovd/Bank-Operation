3. Основной функционал (views.py)

Данный модуль отвечает за формирование JSON-ответа, который используется на главной веб-странице. Основная функция принимает строку с датой и временем в формате YYYY-MM-DD HH:MM:SS и формирует данные для отображения.

Анализ проводится за период от начала месяца до указанной даты. Например, если входящая дата — 20 мая 2020 года, то данные будут обработаны за период с 1 мая по 20 мая 2020 года.

В результате работы функция возвращает JSON, содержащий несколько ключевых блоков. В первую очередь формируется приветствие в зависимости от времени суток: доброе утро, добрый день, добрый вечер или доброй ночи.

Далее рассчитываются данные по банковским картам пользователя. Для каждой карты выводятся последние четыре цифры, общая сумма расходов и кешбэк, который рассчитывается по правилу: 1 рубль за каждые 100 рублей.

Также в ответ включается список топ-5 транзакций по сумме платежа, что позволяет пользователю быстро увидеть самые крупные расходы.

Дополнительно в JSON включаются курсы валют и стоимость акций. Эти данные получаются через внешние API с использованием библиотеки requests. Список валют и акций задается в отдельном файле пользовательских настроек user_settings.json, что делает систему гибкой и настраиваемой.


4. Сервисы (services.py)

Модуль services.py реализует аналитическую часть проекта с использованием элементов функционального программирования.

Основная задача данного модуля — анализ выгодности категорий повышенного кешбэка. Для этого реализована функция, которая принимает данные транзакций, а также год и месяц, за которые необходимо провести анализ.

Функция обрабатывает входные данные и возвращает JSON, в котором показано, сколько кешбэка можно было бы заработать по каждой категории за указанный период. Это позволяет пользователю определить, какие категории являются наиболее выгодными и выбрать их для получения повышенного кешбэка в будущем.

При реализации используются такие подходы, как фильтрация, преобразование и агрегация данных с применением функций высшего порядка, например map, filter и lambda.

Таким образом, модуль services.py отвечает за бизнес-логику и углубленный анализ финансовых данных пользователя.


5. Отчеты (reports.py)

Модуль reports.py предназначен для формирования отчетов и сохранения их результатов в файл.

Ключевым элементом является декоратор, который автоматически записывает результат работы функции-отчета в файл. Декоратор может использоваться как без параметров, так и с параметром. В первом случае имя файла формируется автоматически, во втором — пользователь может задать имя файла самостоятельно.

Один из реализованных отчетов — это отчет по тратам в определенной категории. Функция принимает датафрейм с транзакциями, название категории и опциональную дату. Если дата не указана, используется текущая.

Функция анализирует данные и возвращает сумму расходов по выбранной категории за последние три месяца от заданной даты. Это позволяет пользователю отслеживать динамику своих расходов и лучше управлять финансами.

Модуль также использует логирование для фиксации процесса формирования отчетов и возможных ошибок, а тестирование реализовано с помощью библиотеки pytest, что обеспечивает надежность и корректность работы функционала.
